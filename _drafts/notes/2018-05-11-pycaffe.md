With the hype of Caffe2 around the corner, I'm still feeling like I want to

I'll start with PyCaffe. There are already many tutorial about how PyCaffe,

more about it. Maybe in the future, I'll put some cheatsheet that I've found
useful, as a compensation.

Set up

```bash
export PYTHONPATH=path/to/caffe/python:$PYTHONPATH
```

or

```python
import sys
sys.path.insert(0, 'path/to/caffe/python')
```

How to monitor training process of Caffe with Python interface or PyCaffe.

``` python
import caffe

caffe.set_device(0)
caffe.set_mode_gpu()

solver = caffe.SGDSolver('solver.prototxt')
solver.step(1)
```

## Monitoring training process

### Visualizing caffe architecture

Using caffe script at `$CAFFE/python/draw_net.py`. `graphviz` may be required,
installed using `apt-get`

Or using netscope, an online tool at `http://ethereon.github.io/netscope/#/editor`

quickstart at `http://ethereon.github.io/netscope/quickstart.html`


### Plotting log

To plot caffe log

output log to file using

```bash
2>&1 | tee -a log/my_model.log
```

To parse the log, use Caffe's script at `$CAFFE/tools/extra/parse_log.py`

```bash
# visualize_log.sh
python ~/caffe/tools/extra/parse_log.py my_model.log . # notice the dot in the end
gnuplot -persist gnuplot_commands
```

```bash
# gnuplot_commands
set datafile separator ','
set term x11 0
plot '../my_model.log.train' using 1:4  with line,\
     '../my_model.log.test' using 1:5 with line
set term x11 1
plot '../my_model.log.test' using 1:4 with line
```
