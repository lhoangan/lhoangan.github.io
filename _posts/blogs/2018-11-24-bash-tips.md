# Introduction

I have to say, that the purpose of this post is not to provide basic knowledge
nor an exhaustive perspective on what and how bash terminal should be used. It
 is just a mean to collectively archive the tips and tricks that I have been 
coming across along my journey in learning how to use Linux terminal, especially
bash shell in a more efficient way.

Many of the points here are just trivial and naive to some, and many are useless,
or even untrue and incorrect, so please use at your own risk, but constructive 
comments are always welcome. Yet, please bare in mind that this is more of a 
personal perspective for personal purpose only,so changes are taken place only 
when being perceived to be useful.

The structures and organization are also not perfect, and may not be easy to
be pursued by some, yet it is only to please my own purpose, and will be updated
once I have more time or I feel need to.


## Input mode

### Vi-mode bash

set editing-mode vi
set show-mode-in-prompt on
C-l: clear-screen
set vi-ins-mode-string \1+\2
set vi-cmd-mode-string \1:\2 


### Bracketed paste mode

Enable bracketed paste `printf "\e[?2004h"`

Disable bracketed paste `printf "\e[?2004l"`

Put to your `~/.inputrc`

`set enable-bracketed-paste on`, or

`set enable-bracketed-paste off`

For more details and more of more details see
[Irwin's blog](https://cirw.in/blog/bracketed-paste)
